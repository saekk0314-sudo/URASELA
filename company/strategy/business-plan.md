## 0. ひとことで

**「無料の診断で集めて、継続課金で稼ぐ。売るのはAIとパートナー。」**
完成済みの診断アプリ URASELA を入口に、「診断コンテンツ×AI」の会社をつくる。

| 目標 | 時期 |
| --- | --- |
| 開業 | **2026-11-28** |
| 初売上 | 2026年12月（2027年の年運 完全版） |
| 月商100万円 | 2027年4月（目標）／2027年10月（標準） |
| **年商5000万円ペース（月商約417万円）** | **2027年11月＝開業12ヶ月目（目標）** |
| 法人化 | 2027年7月（目標）／2028年1月（標準） |
| ビジョン | 3年で年商10億円（未検証の目標） |
| オーナーの稼働 | **週1時間以内**（承認・送信・本人確認だけ。自動化で減らす） |

**目標の定義**: 「開業から12ヶ月の売上合計で5000万円」は、初月から毎月平均417万円が必要になり、ゼロからでは現実的ではない。そこで「**12ヶ月目に、年商5000万円のペース（月商417万円以上）に乗せる**」と定義する。この場合、開業12ヶ月の売上合計は約2,400万円になる。

## 1. 現状分析

- **武器**: URASELA（5占術×24問・256通り・相性診断・シェア画像・計測・iPhone対応）。AIでコード・文章・デザイン・分析・動画を内製できる。固定費ゼロのインフラ。
- **足りないもの**: 収益の導線、独自ドメイン、販売アカウント、実績、現状の数字（Q-002で確認）。
- **決まったこと**: 開業日 2026-11-28、事業用口座は使っていない既存の口座、目標は年商5000万円。

## 2. 勝ち筋

1. **原価ゼロの会社の天井は集客力。** だから集客資産（フォロワー・会員・パートナー網・検索流入）を毎週積み上げる。
2. **継続課金で積む。** 無料診断 → 有料レポート → 月額会員 PLUS。受託 → 保守。SaaS とメンバーシップも月額。
3. **人に売ってもらう。** パートナー（紹介料25%）とアフィリエイト（30%）。成果報酬なので手出しゼロ。
4. **小さく数多く試して、当たりに集中する。** 新作診断を毎月1本。外れはすぐ止める。
5. **透明性を広告にする。** AIが社長で、決算を全部公開する。それ自体がニュースになる。

## 5. 集客と販売

1. **無料診断**: URASELA＋毎月の新作。季節企画（年運・バレンタイン・新生活・夏・ハロウィン）に必ず乗る。
2. **SNS**: 「表と裏のギャップ」「相性」「あるある」の型を毎日。縦型動画はAIが自動生成。
3. **広告はルールで回す**: 前月売上の12%まで。ROAS 200%未満は止める（A-013）。
4. **人に売ってもらう**: 受託はパートナー（25%）、講座はアフィリエイト（30%）。コラボ診断は売上を分ける。
5. **実録**: 決算・失敗・意思決定を全部出す。「誰でも稼げる」とは言わない。

## 6. 運営体制

AI組織（CEO＋6部門）が企画・制作・発信・経理を担う。オーナーは承認・本人操作・ストップだけ。規模が大きくなるにつれて、次の2つでオーナーの手間を増やさない。
- **自動化**: 承認済みテンプレの範囲でのメール自動返信、決済後の自動納品（A-015）。
- **人の外部パートナー**: 一次対応・イラスト・営業同行を成果報酬か時間単位で依頼（A-014）。

詳細は [組織図](../org/org-chart.md)・[決裁権限規程](../org/authority.md)・[会議体と運営リズム](../ops/operating-rhythm.md)。

## 8. リスクと対策

| リスク | 対策 |
| --- | --- |
| 新作診断がヒットしない（外れると2027-11の月商は約325万円） | 毎月出して確率を上げる。当たったテーマに広告とコラボを集中 |
| 有料化が却下される・買われない（外れると約325万円） | A-004の承認。価格と導線を週単位で試す |
| 受託が売れない、パートナーが動かない | モニター価格で実績を作る。パートナーには事例と紹介資料を渡す |
| オーナーの負荷が増える | 稼働時間を毎週計測。週1時間を超えたら自動化と外部パートナーで直す |
| サブスクのトラブル（解約できない等の苦情） | 定期購入の表示義務を守り、解約を簡単にする |
| 講座・アフィリエイトの誇大表示 | 収益保証の禁止。紹介者にも「PR」表記を義務づけ、違反は報酬の対象外 |
| 広告・SNSアカウントの停止 | 規約に反する自動化をしない。販路を1つに依存しない |
| AI生成物への規制 | 量産ページを作らない。各プラットフォームのAI規定を守る |
| 税務・法人化のミス | 経理規程・月次決算・納税準備金25%。法人化の前後は税理士に頼む（売上から） |
| 本業の副業規定 | オーナーが就業規則を確認（Q-001） |
| 公開リポジトリからの情報漏えい | 実データは非公開リポジトリだけ |
