# MacでClaudeにChromeを操作させる準備（開業後・Maxに切り替えたら）

> 作成: CEO（AI）/ 2026-11-24。公式の情報（Claudeヘルプ・Claude Codeの文書）をもとにした手順。画面の名前が違ったらスクショを送ってください。
> Chromeを操作する機能（Claude in Chrome）は Pro 以上で使える。画面を何度も読み取るので使用量が多く、実際に回すならMaxのほうが止まりにくい。

## できるようになること・ならないこと

- **できる**：noteへの下書きの貼り付け、Xの予約投稿の入力、ココナラの出品の入力など、毎週くり返す入力作業
- **オーナーが続けてやる**：ログイン、2段階認証、本人確認、CAPTCHA（Claudeはそこで止まって、オーナーに頼む）
- **ルールは同じ**：公開・投稿・送信・購入のボタンは、承認をもらってから押す（A-028で範囲を決める）

## A. いちばん簡単な方法：Chromeの横に出るClaude（サイドパネル）

1. Chromeウェブストアで「Claude」（Claude in Chrome）を開き、「Chromeに追加」を押す
   - https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn
2. 出てきた画面で、Claudeのアカウントでログインする（いつものClaudeと同じアカウント）
3. パズルのピースのアイコン → 「Claude」の横のピンを押して、ツールバーに固定する
4. **KYOVEL用に Chrome のプロフィールを分ける**（右上の人のアイコン → 追加）。事業用のアカウント（note・X・ココナラ）だけでログインしておく
5. サイドパネルの動き方を **「操作の前に確認する」** に切り替える（最初は自動で進む設定になっているため）
6. 使い方：Chromeのツールバーの Claude のアイコンを押す → CEOが用意した「頼み方の文面」を貼る → 画面の動きを見守る

Claudeのデスクトップアプリには、インストール不要の内蔵ブラウザもある（順次使えるようになっている）。どちらを使うかは、アプリの 設定 → Cowork → Preferred browser で選べる。

## B. CEO（このチャット）から直接動かす方法：Remote Control

1. Claudeのデスクトップアプリ（Mac）を入れて、ログインする
2. 設定 → Claude Code → Remote Control で、作業用のフォルダを1つ選ぶ（例：書類の中に作った「KYOVEL」フォルダ。ホームフォルダそのものは選べない）
3. CEOに「つないだ」と送る → こちらから接続をお願いする画面がMacに出るので、許可する
4. Macとアプリが起動している間だけ、CEOがMacのブラウザを使える。終わったら、アプリから接続を切れる

まずはAで試し、慣れてからBに進むのがおすすめ。

## 最初の試し（A-028で承認をもらってから）

- 原稿棚の1本目「はじめる」を、note「URASELA」に**下書き保存まで**入れる（公開しない）
- オーナーが下書きを見て、問題がなければ残りの8本も同じ方法で入れる
- 公開ボタンはオーナーが押す
