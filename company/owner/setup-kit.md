## 7. 各サービスの設定（チェックリスト）

画面の名前が違ったり迷ったりしたら、その画面のスクショを送ってください。次の操作をCEOが指示します。

### 共通（最初に）
- [ ] 事業用のメールアドレスを1つ作る（例: Gmail。名前は「KYOVEL」）。2段階認証をオンにする
- [ ] メールアドレスは、1つのアカウントに1つ必要。Gmailなら「+」をつけた別名（例: `○○+urasela@gmail.com`）が使えることが多い。使えなければ電話番号で登録する
- [ ] パスワードと2段階認証の予備コードは、オーナーだけが保管する（CEOには送らない）

### X（AI社長ゼロ・URASELA公式の2つ）
- [ ] 登録時に生年月日を聞かれたら、オーナー本人のものを入れる（Xの規約で必要）。公開範囲は「自分のみ」にする
- [ ] 名前・ユーザー名・自己紹介・ウェブサイト・アイコンを、1章・2章のとおりに入れる
- [ ] 設定 → セキュリティ → 2要素認証をオンにする
- [ ] 投稿に位置情報をつけない設定にする（初期設定のままなら変更不要）
- [ ] 最初の投稿を「プロフィールに固定」する（投稿の右上「…」→「プロフィールに固定する」）
- [ ] URASELA公式の自己紹介と固定ポストは11/28に貼る（それまではアカウント作成とユーザー名の確保だけ）
- [ ] 予約投稿は、ブラウザ版の x.com の投稿画面にある予約のアイコンから。iPhoneのアプリにも順次入っている

### note（URASELA・AI社長ゼロの2つ）
- [ ] クリエイター名・ID・自己紹介・アイコンを、3章・4章のとおりに入れる
- [ ] アカウント設定の「特定商取引法に基づく表記」を、8章の文案で入れる（URASELAは11/27まで。AI社長ゼロは有料の販売を始めるときでよい）

| メールアドレス | 事業用のメールアドレス |
| 販売価格 | 各記事に表示しています（税込） |
| 商品代金以外に必要な料金 | なし（インターネットの通信料はお客様のご負担です） |
| 支払方法 | noteが定める決済方法 |
| 支払時期・引渡時期 | 購入時に決済され、決済後すぐに全文を読めます |
