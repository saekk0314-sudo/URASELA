**「バズる診断を、AIで、最短7日で。」**

## 1. 現状分析

### 手元にある武器

- **URASELA**: 5占術（四柱推命・西洋占星術・数秘術・九星気学・タロット）×24問で、表16×裏16＝256通りを出す自己分析Webアプリ。相性診断、SNS共有画像、16キャラ個別ページ、OGP・構造化データ・sitemap、GA4・AdSenseの受け皿、iPhone対応まで完成済み。入力はブラウザ内で計算し外部送信しない。2026年8月公開。
- **制作力**: AI（Claude Code）がコード・文章・デザイン・分析・動画（ffmpeg）まで内製できる。外注費ゼロ。
- **固定費ゼロのインフラ**: Cloudflare Pages / GitHub Pages / GitHub Actions。

### 足りないもの

| ギャップ | 影響 | 打ち手 |
| --- | --- | --- |
| 収益導線がない（サイトは「完全無料」方針） | 売上ゼロ | 診断は無料のまま、追加の有料コンテンツ・アフィリエイト・グッズを足す（A-004） |
| 独自ドメインがない | pages.devのままではAdSenseが通りにくい | 初売上で取得（A-005） |
| 販売アカウント・SNSアカウント・開業届がない | 受注も発信もできない | 初週にオーナーがまとめて開設（約2時間、1回きり） |
| 実績・顧客がゼロ | B2Bが売れない | URASELA自体を制作実績にし、モニター価格で最初の3件を取る |
| 現状の数字が不明 | 計画の初期値が仮置き | GA4・AdSenseの状況をオーナーに確認（Q-002） |

## 2. 市場と勝ち筋

- **B2C**: 16タイプ診断・占いはSNSで「結果を見せ合う」文化が定着している。年末年始は占い需要のピーク。URASELAの「表と裏のギャップ」はそのまま話題になる設計。
- **B2B**: 企業・店舗・占い師・インフルエンサーは、集客・LINE登録・ファン化のために診断コンテンツを使う。一方で制作会社の公開価格は「15万円〜」「40万円〜」が並び、中小・個人には重い。**AIで原価を下げ、相場の半額以下・最短7日**で出せば空白を取れる。
- **発信**: 「AIで稼ぐ」系は誇大な情報商材が多く信頼されていない。だからこそ **売上ゼロからの全数字公開** は差別化になる。

## 5. 集客と販売：話題は「設計」する

1. **URASELA**: 「表と裏」のギャップを見せる投稿の型を量産（X・TikTok・Instagram向け縦動画はAIがffmpegで生成）。相性診断はペアで共有されるので拡散係数が高い。12月は年運、2月はバレンタイン相性、4月は新生活の人間関係と、季節イベントに必ず乗せる。
2. **Studio**: ココナラで受け身の受注 → クラウドソーシングの公募に提案 → 実録の読者・URASELAの利用者からの問い合わせ → 公開されている事業者への個別提案（少数・手書き品質・営業お断りの相手には送らない）。
3. **実録**: 「AI社長が売上ゼロから全公開」「オーナーは承認ボタンしか押さない」。毎月の決算を数字で公開し、成功も失敗も出す。**「誰でも稼げる」とは絶対に言わない。**

## 8. リスクと対策

| リスク | 対策 |
| --- | --- |
| 受託が売れない | モニター価格で実績を作る。3ヶ月で3件に届かなければ対象業種・価格・販路を変える |
| AI生成物への規制（検索エンジンのスパムポリシー、各プラットフォームのAI規定） | 量産ページを作らない。1ページずつ価値を確認。プラットフォームのAI利用ルールを出品前に確認 |
| 占い表現の法的リスク（不安をあおる勧誘・誇大表示） | [コンプライアンス規程](../ops/compliance.md)で禁止表現を定義し、公開前に法務チェック |
| 炎上 | 事実だけを強く言う。他者を攻撃しない。実在人物の名前・肖像を使わない |
| プラットフォームのアカウント停止 | 規約違反の自動化をしない。販路を1つに依存しない |
| オーナーの負荷が想定を超える | 稼働時間をKPIで毎週計測し、週30分を超えたら仕組みを直す |
| 税務ミス | 経理規程・月次決算・納税準備金25%・無料相談の活用 |
| 本業の副業規定 | 開業前にオーナーが就業規則を確認（Q-001） |
| 公開リポジトリからの情報漏えい | 実データは非公開リポジトリへ。公開側には規程・ツール・架空サンプルだけ |
