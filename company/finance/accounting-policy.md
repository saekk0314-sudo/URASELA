# 経理規程

> 制定: 2026-11-23 / 所管: 経理財務部（CFOエージェント）/ 承認: オーナー（承認キュー A-002）
> 方針は「攻めるのはマーケ、経理と税務は1円単位で守る」。

## 1. 基本方針

| 項目 | ルール |
| --- | --- |
| 事業形態 | 個人事業（屋号 URASELA）。法人化の判断基準は [法人化計画](incorporation.md)（目標シナリオでは2027年7月設立） |
| 開業日 | **2026-11-28**（オーナー決定）。それより前の準備費用は「開業費」 |
| 会計期間 | 1月1日〜12月31日。初年度（2026年分）は 11月28日〜12月31日 |
| 事業用口座 | オーナーが使っていなかった既存の口座を事業専用にする（オーナー決定）。私用の入出金はしない |
| 記帳 | 複式簿記・発生主義・税込経理（免税事業者の間） |
| 申告 | 青色申告・e-Tax。2027年分は65万円控除（優良な電子帳簿保存まで満たせば75万円） |
| 手出しゼロ | オーナーの財布から事業へお金を入れない。支出は事業の売上の範囲内で、事前承認を得てから |

## 2. 帳簿・証憑の置き場所（重要）

**このリポジトリ（URASELA）は公開リポジトリ。実際の取引データ・顧客情報・口座情報・本名・住所は絶対に置かない。**

- 実データは非公開リポジトリ（例: `urasela-hq`、オーナーが作成。承認キュー A-008）に置く。
  - `ledger/2027.csv` … 仕訳帳（年ごと）
  - `evidence/2027/` … 証憑（請求書・領収書・売上明細のPDF/CSV）
  - `reports/` … 月次決算レポート
- このリポジトリに置くのは、規程・勘定科目・ツール・**架空の**サンプルだけ。
- 口座番号・暗証番号・ネットバンキングのログイン情報は、非公開リポジトリにも書かない（AIは受け取らない）。

### 開業日（2026-11-28）の仕訳

| 状況 | 仕訳 |
| --- | --- |
| 事業用口座に開業日時点で残高がある | `普通預金:事業用 / 元入金` に残高を計上。**この残高は事業の支出に使わない**（手出しゼロ。使うのは事業の売上から） |
| 残高を私用に戻したい | 開業日より前に私用口座へ移しておけば、元入金は0円から始められる（推奨） |
| 開業日より前にオーナーが払った準備費用 | `開業費 / 事業主借`（2026年以降に任意のタイミングで償却） |
| 納税準備用の別口座がある（銀行の目的別口座など） | `普通預金:納税準備` として使う。無い場合は、月次レポートで「事業用口座のうち納税準備分」を金額で管理する |

## 3. 勘定科目

- マスタは [accounts.json](accounts.json)。新しい科目は経理財務部が追加し、月次レポートで報告。
- 補助科目は `科目:補助` で書く（例: `売上高:受託制作`、`売掛金:ココナラ`、`普通預金:納税準備`）。
- 売上高の補助科目は収益源と揃える: `広告` `アフィリエイト` `有料コンテンツ` `グッズ` `受託制作` `保守運用` `メンバーシップ` `テンプレ`。

## 4. 取引別の仕訳ルール

仕訳帳は1行1仕訳（借方＝貸方）。複合仕訳は同じ伝票番号で行を分ける。

| 取引 | 借方 | 貸方 | ポイント |
| --- | --- | --- | --- |
| ココナラで受託完了 | 売掛金:ココナラ（総額） | 売上高:受託制作 | **総額で売上計上**し、手数料は別行 |
| 同・販売手数料22% | 支払手数料 | 売掛金:ココナラ | |
| プラットフォームから振込 | 普通預金:事業用 | 売掛金:◯◯ | 振込手数料は支払手数料 |
| note・AdSense等の月次確定 | 売掛金:◯◯ | 売上高:◯◯ | 確定月に計上（発生主義） |
| 企業へ請求（源泉徴収あり） | 売掛金:取引先 | 売上高:受託制作 | 請求額の総額で計上 |
| 同・入金 | 普通預金 ＋ 事業主貸（源泉所得税） | 売掛金:取引先 | 天引き分は確定申告で精算されるので事業主貸 |
| オーナー個人のカードで経費 | 経費科目 | 事業主借 | 原則は事業用口座から払う |
| オーナーへの引き出し | 事業主貸 | 普通預金:事業用 | 個人事業主に給与はない |
| 納税準備金の振替 | 普通預金:納税準備 | 普通預金:事業用 | 営業利益の25%（目安） |
| 開業日前の準備費用 | 開業費 | 事業主借 | 2027年以降に任意償却（減価償却費） |

**源泉徴収**: 企業がデザイン料・原稿料として個人に支払う場合、10.21%（100万円以下の部分）を天引きされることがある。見積の段階で取引先に確認し、請求書に「源泉徴収税額」欄を設ける。

**家事按分**: 自宅のネット回線・スマホ・オーナーが契約しているAIサービスは、事業での使用割合（時間・用途の記録に基づく）で按分して経費化できる。按分の根拠をメモに残す。

## 5. 証憑と電子帳簿保存法

- メール・Web・プラットフォームで受け取った請求書・領収書・売上明細は**電子データのまま保存**（紙に印刷して捨てるのは不可）。
- ファイル名は `YYYYMMDD_取引先_金額.拡張子`（例: `20270120_ココナラ_30000.pdf`）。仕訳帳の「証憑」列にこの名前を書く。
- 改ざん防止は「事務処理規程」の備え付けで対応（下の付録。オーナー承認で制定）。
- 売上高5,000万円以下のため、税務調査でデータのダウンロードの求めに応じられれば検索機能の要件は不要。それでもファイル名規則で検索できる状態を保つ。
- 保存期間: 帳簿・証憑とも7年（青色申告）。

## 6. 月次決算（毎月5営業日目まで）

| 手順 | 担当 | 所要 |
| --- | --- | --- |
| 1. 事業用口座の入出金明細CSV、各プラットフォームの売上明細をダウンロードして非公開リポジトリへ置く | **オーナー** | 5分 |
| 2. 明細から仕訳を起こし `ledger/YYYY.csv` に追記 | 経理財務部 | |
| 3. `ledger.mjs check` → 試算表 → 口座残高・プラットフォーム残高と一致確認 | 経理財務部 | |
| 4. 月次損益・予実差異（計画比±30%超は原因分析） | 経理財務部 → CEO | |
| 5. 納税準備金の振替額を算出し、オーナーへ振替依頼 | 経理財務部 → **オーナー** | 1分 |
| 6. 月次レポートを作成し、承認キューに載せる | CEO | |

手順は `.claude/skills/monthly-close` に定義。

## 7. 支出ルール

1. **事前承認**: すべての支出は承認キューに「金額・目的・期待効果・代替案」を載せ、オーナー承認後に実行。ただし、オーナーが包括承認したルールの範囲内の支出は個別承認を省き、月次決算で報告する。
2. **財源**: 前月末時点の手元資金（納税準備金を除く）の範囲内。借入・後払いで資金を先食いしない。
3. **広告は予算ではなくルールで回す**（A-013承認後）: 前月売上の12%を上限に広告を出し、ROAS（広告費1円あたりの売上）が200%を下回った広告は止める。成果報酬の支払い（パートナー紹介料25%・講座のアフィリエイト報酬30%）は売上が立ったときだけ発生するので、手出しゼロと両立する。
4. **定額課金の見直し**: サブスク契約は四半期ごとに費用対効果を確認し、効果がなければ解約。

## 8. 請求・入金

- 見積・請求は [請求書テンプレ](templates/invoice-template.md) で作成。番号は `INV-YYYYMM-連番`。
- 支払条件は原則「納品月末締め・翌月末払い」。着手金50%（10万円以上の案件）。
- 免税事業者の間は、請求書に登録番号を書かず、消費税額を内訳表示しない（総額表示）。
- 入金遅延は期日翌営業日にリマインド文面を作成し、オーナー承認で送付。

## 9. 年次決算・確定申告

| 時期 | 作業 | 担当 |
| --- | --- | --- |
| 1月第1週 | 前年の決算整理（未収・未払・開業費償却）、`ledger.mjs close` で期首残高仕訳。2026年分（11/28〜12/31）が最初の決算 | 経理財務部 |
| 1月中 | 支払調書・源泉徴収の突合、`ledger.mjs blue` で青色申告決算書の転記額を作成 | 経理財務部 |
| 2月中旬 | 申告書の入力値一覧（本業の源泉徴収票と合算）を作成し、オーナーへ | 経理財務部 |
| 3月15日まで | e-Taxで送信（マイナンバーカード＋スマホ、約20分）。住民税は「自分で納付」を選ぶ | **オーナー** |

税額の最終確認には、税務署の無料相談・商工会議所の記帳指導（無料）を使う。顧問税理士は、売上や法人化で必要になった段階で費用対効果を見て検討する。

## 付録: 電子取引データの訂正及び削除の防止に関する事務処理規程（案）

> 国税庁の個人事業者向けサンプルを参考に作成。オーナー承認日をもって施行し、非公開リポジトリにも同じ文書を置く。

1. **目的**: この規程は、電子計算機を使用して作成する国税関係帳簿書類の保存方法等の特例に関する法律第7条に定められた電子取引の取引情報に係る電磁的記録の保存義務を適正に履行するために必要な事項を定める。
2. **適用範囲**: 屋号URASELAの事業における電子取引の取引情報に係る電磁的記録に適用する。
3. **管理責任者**: 事業主（オーナー）とする。日常の保存作業はCEO（AI）および経理財務部が補助する。
4. **訂正削除の原則禁止**: 保存する取引関係情報の内容について、訂正又は削除をすることは原則禁止とする。
5. **訂正削除を行う場合**: 業務処理上やむを得ない理由により訂正又は削除する必要がある場合は、訂正削除の日付・内容・理由・処理担当者を記録し、変更前のデータとともに保存する（非公開リポジトリのコミット履歴を記録として用い、履歴の書き換え〈force push等〉は禁止する）。
6. **保存期間**: 取引の日の属する年の翌年3月15日の翌日から7年間保存する。
7. **施行**: この規程は、オーナーが承認した日から施行する。
