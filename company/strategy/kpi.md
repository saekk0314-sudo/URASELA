# KPI設計

> 所管: 経営企画室。週次経営会議で毎週確認し、月次決算で計画値と並べる。

## 北極星と制約

| | 指標 | 目標 |
| --- | --- | --- |
| 北極星 | **月間営業利益** | 2027年11月に100万円（標準シナリオ） |

## KPIツリー

```
月間営業利益
├─ URASELA（自社メディア）
│   ├─ セッション数 ………… SNS投稿数 × 反応率、季節企画、検索流入
│   ├─ 診断完了率 ………………… 完了数 ÷ セッション（目標40%）
│   └─ 収益化
│       ├─ 広告: セッション × 単価（独自ドメイン＋AdSense承認後）
│       ├─ アフィリエイト: 診断完了 × クリック率 × 成約率 × 報酬
│       └─ 有料コンテンツ: 診断完了 × 購入率（目標0.4%）× 単価
├─ URASELA Studio（受託）
│   ├─ 受注件数 = 問い合わせ数 × 受注率
│   │   └─ 問い合わせ = ココナラ閲覧 × 問い合わせ率 ＋ 提案数 × 返信率 ＋ 実録経由
│   ├─ 平均単価（3万円 → 20万円）
│   └─ 保守契約数 = 納品数 × 移行率（40%）− 解約
├─ 実録「AI社長」
│   ├─ フォロワー数・表示回数
│   └─ 会員数 × 500円 ＋ テンプレ販売数 × 1,980円
└─ 費用（手数料率・成長投資枠）
```

## 週次で見る数字

| 部門 | 指標 | 取り方 | 誰が |
| --- | --- | --- | --- |
| マーケ | URASELAセッション・診断完了・共有クリック | GA4 | オーナーがスクショを1枚送る → 経営企画室が転記 |
| マーケ | X投稿数・表示回数・フォロワー | Xのアナリティクス | 同上 |
| 営業 | ココナラ閲覧・問い合わせ・提案・受注・平均単価 | ココナラ管理画面 | 同上 |
| 実録 | note会員数・記事PV | noteのダッシュボード | 同上 |
| 経理 | 売上・営業利益・手元資金・売掛金 | 帳簿（月次） | 経理財務部 |
| 運営 | 承認待ち件数・承認までの日数・オーナー稼働時間 | 承認キュー・決裁ログ | CEO |

**オーナーに頼む数字は「スクショ3枚（GA4・ココナラ・note）」まで。** それ以上欲しくなったら、AI側で取得を自動化する（GA4のAPI連携などはフェーズ2で検討）。

## 月次目標（標準シナリオ）

[PL計画](../finance/pl-plan.md) の「標準シナリオの主要KPI」表が月次目標。実績が計画比±30%を超えた指標は、翌週の経営会議でCEOが原因と打ち手を出す。

## 指標の定義

| 指標 | 定義 |
| --- | --- |
| セッション | GA4のセッション数（同意したユーザーのみ計測されるため、実数より少なめに出る点に注意） |
| 診断完了 | 最終結果画面の表示イベント数 |
| 受注率 | 受注件数 ÷ 見積・提案を出した件数 |
| 保守移行率 | 保守契約を結んだ納品先 ÷ 前月の納品件数 |
| オーナー稼働時間 | オーナーが承認・送信・本人確認・アップロードに使った時間（自己申告。承認キューの各項目に見込み時間を書き、実績で補正） |
