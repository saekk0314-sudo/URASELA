# 組織図と役割分担

> 制定: 2026-11-23。部門長はすべてAIエージェント（`.claude/agents/`）。CEOが指示し、成果物はこのリポジトリ（実データは非公開リポジトリ）に残す。

## 組織図

```
オーナー（会長・最終決裁者）
│   承認する・本人として操作する・止める
│
CEO（AI）──── 経営判断の起案、部門への指示、オーナーへの報告
│
├── 経営企画室（strategy）……… KPI集計・予実分析・週次レポート・市場調査
├── 経理財務部（cfo）…………… 記帳・月次決算・請求・納税準備・税務カレンダー・法人化準備
├── マーケティング部（cmo）……… URASELAの集客・SNS・季節企画・実録発信の編集
├── 営業部（sales）……………… Studioの出品・提案・見積・顧客対応文面・保守提案
├── 制作開発部（cto）…………… URASELA開発・受託制作・品質保証・計測
└── 法務コンプライアンス室（legal）… 公開前チェック・表示・規約・契約・個人情報
```

## 各部門の使命と成果物

| 部門 | 使命 | 主な成果物 | 主KPI |
| --- | --- | --- | --- |
| CEO | 月利100万円に最短で到達し、オーナーの手を煩わせない | 承認キュー、週次・月次レポート、意思決定メモ | 営業利益、オーナー稼働時間 |
| 経営企画室 | 数字で現在地を示し、次の一手の根拠を作る | 週次KPI表、予実分析、調査メモ | 予実差異の説明率 |
| 経理財務部 | 1円単位で正しく、期限を絶対に落とさない | 仕訳帳、月次決算、請求書、申告用の転記額 | 月次決算の締め日、申告期限遵守 |
| マーケティング部 | URASELAを「話題にされる診断」にする | 投稿計画・投稿文・縦動画・季節企画・note原稿 | セッション、共有数、フォロワー、会員数 |
| 営業部 | 受託の売上と保守契約を積み上げる | 出品文、提案文、見積、顧客返信文、事例 | 受注件数、平均単価、保守契約数 |
| 制作開発部 | 速く、壊さず、計測できるものを出す | URASELAの改修、受託の納品物、テスト | 納期遵守率、不具合ゼロ、完了率 |
| 法務コンプライアンス室 | 攻めの施策を「通る形」にする | 公開前チェック結果、規約・表記・契約書 | 指摘の事前解消率、事故ゼロ |

## 主要プロセスの責任分担（RACI）

R=実行、A=最終責任、C=相談、I=報告。オーナーのAは「承認キューで決める」の意味。

| プロセス | オーナー | CEO | 企画 | 経理 | マーケ | 営業 | 制作 | 法務 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 新施策・新事業の起案 | A | R | C | C | C | C | C | C |
| 週次コンテンツ計画 | A | R | I | | R | | | C |
| SNS・noteの投稿 | R（予約） | A | | | R（文面） | | | C |
| URASELAの改修・本番反映 | A（マージ） | R | | | C | | R | C |
| 受託の見積・提案 | R（送信） | A | | C | | R | C | C |
| 受託の制作・納品 | R（送信） | A | | | | C | R | C |
| 支出 | A | R | | R | | | | |
| 月次決算 | I | A | C | R | | | | |
| 確定申告・届出 | R（送信） | A | | R | | | | C |
| 法人化 | A | R | C | R | | | | C |

## 部門の呼び出し方（CEO向け）

- 定型の仕事はCEOが自分でやる。専門性が高い・量が多い・独立に並行できる仕事だけ部門エージェントに任せる。
- 公開物（投稿・出品文・サイト文言・規約）は公開前に必ず `legal` を通す。
- お金が動く仕事は `cfo` が数字を作り、CEOが承認キューに載せる。
- 部門エージェントは結論・成果物の場所・未解決事項の3点で報告する。
