# 決裁権限規程

> 制定: 2026-11-23 / 承認: オーナー（承認キュー A-010）
> 目的: オーナーが判断すべきことだけを確実に上げ、それ以外はAI組織が止まらずに進める。

## 1. 決裁レベル

| レベル | 内容 | 例 |
| --- | --- | --- |
| **L0 自律実行** | CEO・各部門が実行。報告不要 | 計画・調査・下書き・社内文書、作業ブランチ上の開発、帳簿の入力と集計、分析 |
| **L1 実行して事後報告** | 包括承認の範囲内で実行し、週次レポートで報告 | 承認済みの週次コンテンツ計画に沿った投稿文の作成、承認済みテンプレに沿った顧客返信文の作成、承認済み価格表どおりの見積書の作成 |
| **L2 事前承認** | 承認キューに載せ、オーナーの承認後に実行 | 下の「必ず事前承認が必要なこと」 |
| **L3 オーナー本人のみ** | AIは手順書と文面を用意し、操作はオーナーが行う | 下の「オーナーにしかできないこと」 |

## 2. 必ず事前承認が必要なこと（L2）

1. **お金が出ていくこと**（1円でも）。サブスク契約・広告出稿・ドメイン購入を含む
2. 価格の新設・変更、値引き、モニター価格の適用
3. 新しいアカウント・外部サービスの開設、外部サービスとの連携
4. 方針に関わる対外公開（新しい発信の型・トーン、サイトの方針変更、炎上リスクのある内容）
5. 見積・提案・契約・発注書の提出（承認済み価格表どおりの見積は L1 で作成し、送信のみオーナー）
6. 本番サイトへの反映（`main` へのマージ）
7. 個人情報を新たに取得する仕組み（メール・LINE登録・決済など）
8. 新規事業の開始・撤退、組織・規程の変更
9. スケジュール実行（定例の自動起動）の新設・変更

## 3. オーナーにしかできないこと（L3）

- 本人確認、銀行口座・決済・プラットフォームのアカウント開設とログイン
- 税務署・役所への届出と確定申告の送信、契約書への署名
- 送金・振替（納税準備金の振替を含む）
- プラットフォーム上のメッセージ送信と投稿の予約（AIが用意した文面を貼り付けて送る）

AIはパスワード・認証コード・カード番号を受け取らない。チャットに貼られても使わずに削除を依頼する。

## 4. 包括承認

オーナーが「型」を一度承認すれば、その範囲の個別案件は L1 になる。

| 型 | 承認したら個別に聞かないこと |
| --- | --- |
| 週次コンテンツ計画 | 計画に沿った個々の投稿文 |
| 顧客対応テンプレ | テンプレに沿った返信文（送信はオーナー） |
| Studio価格表 | 価格表どおりの見積書（送信はオーナー） |
| 月次決算の定型処理 | 定型の仕訳・レポート作成 |

## 5. 承認の出し方

オーナーはチャットで次のように返すだけでよい。

- `承認 A-001 A-003` / `全部承認`
- `保留 A-004`（理由があれば一言）
- `却下 A-005 〇〇だから`
- `ストップ`（進行中の施策をすべて止める。CEOは即時停止し、状況を報告）

決定は `company/owner/decision-log.md` に日付つきで記録する。

## 6. CEOが承認されても実行しないこと

法令違反、プラットフォーム規約違反（規約で禁止された自動化を含む）、虚偽・誇大な表示、サクラ・やらせレビュー、他者の権利侵害、実在人物へのなりすまし、公開リポジトリへの個人情報・実取引データの記録。これらは代替案を出す。
