```
├─ URASELA（B2C）

│   ├─ PLUS ……………………… 在籍数 × 480円（在籍数＝前月在籍 − 解約（約10%）＋ 新規入会）
│   └─ 広告・アフィリエイト … セッション・診断完了 × 単価
├─ Studio（B2B）
│   ├─ 受託 ………………………… （自社販売＋パートナー紹介＋ココナラ）× 受注率 × 単価
│   ├─ 保守 ………………………… 納品数 × 移行率（50%）− 解約
│   └─ AI導入支援 ……………… 実録・講座からの問い合わせ × 受注率 × 40万円

└─ 実録
    ├─ メンバーシップ ………… フォロワー × 入会率 × 500円
    └─ 講座 ………………………… （自社＋アフィリエイト）× 29,800円
```

## 物差し（ユニットエコノミクス）

| 指標 | 合格ライン |
| --- | --- |
| 広告のROAS（広告費1円あたりの売上） | 200%以上。下回った広告は止める |
| LTV ÷ CAC（顧客生涯価値 ÷ 獲得単価） | 3倍以上 |
| PLUSの月の解約率 | 10%以下 |
| PLUSの獲得単価 | 約1,300円以下 |
| 新作診断の初速 | 公開2週間で1万セッション（届かなければ作り込まない） |

## 月次目標

[PL計画](../finance/pl-plan.md) の「目標シナリオの主要KPI」の表が月次目標。目標比 −30% を超えた指標は、翌週の経営会議で原因と打ち手を出す。2ヶ月続いたら、その打ち手を縮小して勝っている打ち手に資源を移す。

## 指標の定義

| 指標 | 定義 |
| --- | --- |
| セッション | GA4のセッション数（同意したユーザーだけが計測されるため、実数より少なめに出る） |
| 診断完了 | 最終結果画面の表示イベント数 |
| PLUS在籍数 | 月末時点の有料会員数 |
| 受注率 | 受注件数 ÷ 見積・提案を出した件数 |
| ROAS | 広告経由の売上 ÷ 広告費 |
| オーナー稼働時間 | 承認・送信・本人確認・契約・アップロードに使った時間（自己申告） |
