## 1. 手本から取り込む考え方

出典について: 2026-11-23時点でWeb検索の結果から確認した範囲で書いている。記事の本文はこのセッションから接続できず、直接は読めていない。リンクを付けたのは、検索結果でその記事の発言だと示されたものだけ。それ以外は「報道ベース」とした。

| 手本の考え方 | 当社での翻訳 |
| --- | --- |
| **広告が一番大事。** 商品への思い入れからではなく、売れる攻略法から商品を作った（[Excite/BestTimes のインタビュー](https://www.excite.co.jp/news/article/BestTimes_01044859/)） | AIは商品を一晩で作れる。差がつくのは**売り方（集客）だけ**。経営資源の大半を集客の仕組みに使い、商品は「売れる証拠」が出てから磨く |
| **会議も予算も事業計画もムダ。** 慣習を壊す経営で急成長した（[スマート会議術のインタビュー](https://www.kaigishitu.com/meeting-hacks/detail/interview/smart-meeting/32675/)） | 計画は「賭けの一覧」として持つだけ。会議は5分、決裁はチャット1行。広告は予算を組まず、ルール（ROAS）で自動的に増やす・止める |
| 自分の失敗や転落も隠さず発信したことで、再び注目を集めた（報道ベース） | **透明性そのものを最大の広告にする。** 決算・失敗・意思決定の過程を実録で全部出す |
| 「お金を稼ぐのは悪」という空気を払拭したい、と語っている（報道ベース） | お金の話は堂々とする。ただし盛らない、煽らない、「誰でも稼げる」と言わない |
| 新しい会社で、設立から短期間で売上100億円という大きな目標を掲げている（報道ベース） | 目標は小さく置かない。1年目は**年商5000万円ペース**（オーナー決定）、ビジョンは**3年で年商10億円** |

あわせて当社の原則として、**「自分が欲しいのに無いもの」から作る**。占いの当たり外れではなく、「自分と相手の取扱説明書が毎月ほしい」という不満から月額会員 PLUS を作る。

## 2. CEOとしての判断軸

1. **原価ゼロの会社の天井は「集客力」で決まる。** フォロワー、会員リスト、パートナー網、検索流入のように、積み上がる集客資産を毎週増やす。
2. **単発より継続。** すべての商品を継続課金につなげる。入口は無料の診断、次に単品の有料レポート、その先に月額のPLUS・SaaS・保守・メンバーシップ。
3. **自分で売らない（レバレッジ）。** パートナー（紹介料25%）、アフィリエイト（30%）、コラボ診断（売上を分ける）を使う。払うのは**売れたときだけ**なので、手出しゼロのまま販売力を借りられる。
4. **小さく数多く試し、勝ったら一点集中。** 新作診断を毎月1本出す。LP・価格・コピーを週単位で試す。外れはすぐ止めて、当たりに人（AI）とお金を寄せる。
5. **話題は設計する。** 「AIが社長」「決算を全公開」「表と裏」は、それ自体がニュースになる。毎月1回は「数字の節目」や「新作」で話題を作る。
6. **守りは鉄壁。** 攻める会社ほど、税務・表示・契約のミス1つで全部を失う。経理と税務は1円単位、表示は法務チェックを通してから。

## 3. 数字の物差し（ユニットエコノミクス）

| 指標 | ルール |
| --- | --- |
| 広告 | ROAS（広告費1円あたりの売上）200%以上を保つ。下回った広告は止める。上限は前月売上の12% |
| 顧客獲得 | LTV（顧客生涯価値）÷ CAC（獲得単価）が3倍以上。回収は2ヶ月以内 |
| PLUS（月額480円） | 手数料を引くと約410円。毎月約1割が解約する前提で、LTVは約4,100円 → 1人あたり約1,300円までなら広告で獲得してよい |
| 受託 | 紹介料25%を払っても、粗利率は60%以上を保つ |
| 講座 | アフィリエイト報酬30%を払っても、粗利率は60%以上を保つ |

## 5. 手本と変えるところ（やらないこと）

- お金配り・懸賞など、資金を使う話題づくりはしない（手出しゼロ。景品表示法やプラットフォーム規約のリスクもある）。
- 炎上を狙わない。話題は事実と数字で作る。
- 誇大広告・ステルスマーケティング・根拠のない数字は使わない。アフィリエイトやパートナーにも「PR」の表記を守らせる。
- 実在の人物の名前で売らない。
