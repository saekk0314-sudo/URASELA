# オーナーの仕事（これだけ読めばOK）

> オーナー＝会長・最終決裁者。会社を動かすのはCEO（AI）とAI組織。
> オーナーの仕事は **①承認する ②本人として操作する ③止める** の3つだけ。

## 1. やること・やらないこと

| オーナーがやる | AIがやる（オーナーはやらない） |
| --- | --- |
| 承認キューに「承認」「保留」「却下」と返す | 企画・計画・数字づくり |
| 口座・アカウントの開設、ログイン、本人確認 | 投稿文・出品文・提案文・返信文の作成 |
| AIが用意した文面を貼り付けて送る・予約する | サイトの開発・受託の制作 |
| 振替・支払い・届出と申告の送信 | 記帳・月次決算・請求書・申告の数字 |
| 「ストップ」と言う | 期限の管理とリマインド |

## 2. CEOへの話しかけ方（チャットで一言）

| 送る言葉 | 返ってくるもの |
| --- | --- |
| `状況は？` | 現在地を5行で |
| `週次` | 週次経営会議の結果（数字・承認事項・今週の投稿と文面一式） |
| `月次` | 月次決算（売上・利益・振替額） |
| `承認 A-001 A-003` / `全部承認` | 承認済みの仕事への着手報告 |
| `保留 A-004` / `却下 A-005 理由` | 代替案（次の週次会議で） |
| 問い合わせ文をそのまま貼る | そのまま送れる返信文 |
| `ストップ` | すべての施策を止めて状況報告 |

**パスワード・認証コード・カード番号はチャットに貼らないでください。** AIはそれらを使いません。

## 3. 初期セットアップ（承認キュー A-003 を承認したら、1回だけ・約2時間）

上から順に。各サービスで迷ったら、その画面のスクショを送ってもらえればCEOが次の操作を指示します。

| 順 | やること | 目的 | 目安 |
| --- | --- | --- | --- |
| 1 | 事業用メールアドレスを1つ作る（例: Gmail） | 以下のアカウントをまとめる。私用と分ける | 5分 |
| 2 | 事業用のネット銀行口座を開く（個人名義で可。月額無料のネット銀行） | 売上の入金・経費の支払いを私用と分ける | 15分＋審査 |
| 3 | GitHubで非公開リポジトリ `urasela-hq` を作る（New repository → Private） | 帳簿・証憑・顧客情報の置き場所（A-008） | 2分 |
| 4 | Xのアカウントを2つ（AI社長用・URASELA公式用） | 発信 | 10分 |
| 5 | noteのアカウント（AI社長用） | 実録・メンバーシップ・有料記事 | 5分 |
| 6 | ココナラに登録し、出品者として本人確認 | 受託の受注（出品文はCEOが用意） | 15分 |
| 7 | アフィリエイトのASPに登録（もしもアフィリエイト・A8.net など）し、サイト `https://urasela.pages.dev` を登録 | URASELAの収益化 | 15分 |
| 8 | 出品文・プロフィール・初週の投稿を貼り付けて予約 | 発信開始 | 20分 |
| — | （1月に）開業届と青色申告承認申請書をe-Taxで提出 | 開業 | 20分 |
| — | （2月以降）SUZURI・クラウドワークス | グッズ・受託の販路 | 各10分 |

アカウント名・プロフィール文・アイコンは、CEOが一式用意してから渡します。

## 4. 立ち上げ後の1週間

| いつ | やること | 時間 |
| --- | --- | --- |
| 月曜 | 週次レポートを読んで承認を返す | 5分 |
| 月曜 | 今週の投稿を予約（X・note） | 15分 |
| 随時 | 問い合わせが来たら貼る → 返ってきた返信文を送る | 1件2分 |
| 月初 | 口座・プラットフォームの明細をダウンロードして `urasela-hq` に置く → 納税準備口座へ振替 | 6分 |

**目標は週30分以内。** 超えた週は教えてください。仕組みの方を直します。

## 5. CEOにできないこと（正直に）

- 自分でログイン・送信・振込・申告の送信はできない（オーナーの名義と責任で行う操作だから）。
- 24時間ずっと動いているわけではない。チャットで話しかけたとき、または承認したスケジュール実行（週次・月次）のときに動く。
- 成果は保証できない。計画と実績を毎月並べて、外れたら直し方を出す。
